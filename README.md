# 个人主页

无需安装依赖。双击 index.html 即可本地浏览；样式和脚本均使用相对路径，支持 GitHub Pages。头像需要联网加载。

## 修改资料

编辑 profile.js 中的 name、intro、bio、tags 和 projects。当前只填入已确认的 GitHub 用户名和头像，未编造履历或作品，未公开连接账号返回的邮箱。

## 发布到 GitHub Pages

1. 在自己的 GitHub 中创建公开仓库 `yzygbtfxdr-stack.github.io`（若已存在则使用已有仓库）。
2. 将 index.html、style.css 和 profile.js 上传至仓库根目录。
3. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 / (root)，保存。
4. 等待 Pages 部署完成后，主页地址为 https://yzygbtfxdr-stack.github.io/ 。此地址为预期地址，当前尚未部署。

若想使用现有项目仓库，也可以上传到该仓库；Pages 地址会包含仓库名称。
